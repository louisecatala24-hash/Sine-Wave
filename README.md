# Sine Wave Visualization

This Python program computes and plots the sine wave:

y(t) = 12 sin(2π × 7t)

It prints the computed amplitudes at ten selected times and marks those points on the graph.

## Requirements

- Python 3
- NumPy
- Matplotlib

## Installation

Install the required libraries:

```bash
python -m pip install numpy matplotlib
```

## How to Run

Open a terminal in the folder containing `sine_wave.py`, then run:

```bash
python sine_wave.py
```

## Wave Parameters

- Amplitude: 12
- Frequency: 7 Hz
- Phase: 0 radians
- Time range: 0 to 0.35 seconds
- Plotting points: 500

## Expected Output

1. A terminal table showing the selected times and computed amplitudes.
2. A sine wave graph with red markers and coordinate labels for the selected points.

Close the graph window to finish the program.
